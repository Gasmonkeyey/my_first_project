# Ответы на вопросы

## 1. Какое свойство включает Flexbox?
display: flex. Дочерние элементы становятся flex-элементами и выстраиваются вдоль основной оси.

## 2. Разница justify-content и align-items?
justify-content — по основной оси (горизонталь при row). align-items — по поперечной (вертикаль при row).

## 3. Что делает flex-direction?
Задаёт направление основной оси. Значения: row, row-reverse, column, column-reverse.

## 4. Значение flex: 1?
flex: 1 = flex-grow: 1, flex-shrink: 1, flex-basis: 0%. flex-grow — растёт, flex-shrink — сжимается, flex-basis — базовый размер.

## 5. Как работает flex-wrap?
Переносит элементы на новую строку. Значения: nowrap, wrap, wrap-reverse. Нужен, когда элементов больше, чем помещается в строку.

## 6. align-content vs align-items?
align-items — выравнивает элементы в одной строке. align-content — выравнивает строки при flex-wrap и нескольких строках.

## 7. Как работает order?
Меняет порядок отображения. По умолчанию 0, меньшее значение — раньше. Полезно для перестановки без правки HTML.

## 8. Main axis и cross axis?
Main axis — основная ось, задаётся flex-direction. Cross axis — перпендикулярна ей. При row: main — горизонталь, cross — вертикаль.

## 9. Адаптивный макет без медиа-запросов?
flex-wrap: wrap + flex: 1 1 300px. Карточки переносятся и растягиваются сами.

## 10. Преимущества gap?
Задаёт промежутки без лишних margin, не создаёт отступов по краям, работает только внутри flex/grid. Проще и чище.
