## 1. Какие инструменты графического редактора наиболее полезны для извлечения информации о размерах, цветах и шрифтах?
Панель свойств (Properties) — показывает X/Y, ширину/высоту, цвет, шрифт. Инструмент Inspect (в Figma) — CSS-код и стили. Плагины вроде "Figma to CSS".

## 2. Как правильно организовать структуру CSS-переменных на основе данных из макета?
Разбить на категории: цвета (primary, secondary, text, bg), типографика (размеры, line-height), тени, градиенты. Именовать по смыслу: `--color-primary`, `--font-size-lg`.

## 3. Какие метрики из макета наиболее критичны для точной верстки?
Ширина контейнера, отступы (padding/margin), размеры шрифтов и межстрочные интервалы, цвета, радиусы скругления.

## 4. Как определить систему сетки в макете и перенести в CSS Grid/Flexbox?
В Figma посмотреть Layout Grid. Обычно 12-колоночная сетка. В CSS — `display: grid; grid-template-columns: repeat(12, 1fr);`. Для карточек — `repeat(3, 1fr)`.

## 5. Какие сложности при переносе типографии из макета в веб?
Разные рендеринги шрифтов в браузерах, отсутствие нужного шрифта, разница в line-height (в Figma — проценты, в CSS — множители).

## 6. Как обрабатывать адаптивность, если в макете только десктоп?
Добавлять брейкпоинты по типичным размерам (1024px, 768px, 480px), использовать относительные единицы (%, rem, vw), flex-wrap, grid auto-fit.

## 7. Какие инструменты браузера помогают сравнивать с макетом?
DevTools → Inspect, измерение отступов, Color Picker, наложение (в некоторых браузерах). Расширения типа "PerfectPixel".

## 8. Как правильно экспортировать изображения для веба?
Экспорт в SVG для иконок и логотипов, WebP/JPEG для фото, PNG для прозрачности. Оптимизировать через TinyPNG, указывать `width`/`height`.

## 9. Что делать, если в макете шрифты, которых нет в веб-доступе?
Найти похожий веб-шрифт (Google Fonts), либо купить лицензию и подключить через `@font-face`, либо использовать fallback.

## 10. Какие методологии помогают поддерживать соответствие макета и кода?
БЭМ (Блок-Элемент-Модификатор), Atomic Design, дизайн-токены (CSS-переменные), регулярное сравнение через DevTools и скриншоты.
