# Ответы на вопросы

## 1. Разница между селектором по классу и по ID?
Класс (.class) — специфичность 0,1,0, может повторяться. ID (#id) — специфичность 1,0,0, уникален на странице. Классы — для групп, ID — для уникальных элементов.

## 2. Как работает каскад в CSS?
При конфликте: 1) !important, 2) специфичность, 3) порядок в файле. Побеждает последнее при равной специфичности.

## 3. Специфичность селекторов:
- ul li.important → 0,1,2
- #site-title → 1,0,0
- .content > .featured-post → 0,2,0

## 4. Наследуемые и ненаследуемые свойства:
Наследуются: color, font-family, font-size, line-height.
Не наследуются: margin, padding, border, background.

## 5. Селектор > и селектор потомков?
> — только прямые дети. Пробел — все потомки на любой глубине.

## 6. Для чего :hover и :nth-child()?
:hover — стиль при наведении. :nth-child() — выбор по порядку (зебра, чётные/нечётные).

## 7. Что делает !important?
Переопределяет все правила. Ломает каскад, усложняет отладку.

## 8. Как ::before и ::after расширяют CSS?
Вставляют контент до/после элемента через content. Текст, символы, иконки, декор.

## 9. Порядок при одинаковой специфичности?
Побеждает правило, объявленное ниже в файле.

## 10. Как DevTools помогают отлаживать CSS?
Показывают применённые стили, Computed, зачёркнутые правила, позволяют менять значения на лету.
