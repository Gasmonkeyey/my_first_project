## 1. В чем разница между временной сложностью O(n) и O(n²)? Приведите примеры алгоритмов с каждой сложностью.
O(n) — время растёт линейно с размером данных (поиск максимума, перебор массива). O(n²) — квадратично (вложенные циклы: пузырьковая сортировка, сортировка вставками).

## 2. Как работает алгоритм бинарного поиска и почему его сложность O(log n)?
Массив делится пополам, сравнивается средний элемент с искомым. Если меньше — ищем в левой половине, если больше — в правой. На каждом шаге область поиска уменьшается вдвое → log₂(n) шагов.

## 3. Какие преимущества и недостатки у пузырьковой сортировки по сравнению с другими?
Плюсы: простая реализация, понятная логика, устойчивая. Минусы: O(n²) — медленная на больших данных, много обменов. Для больших массивов лучше быстрая сортировка или слиянием.

## 4. Как оптимизировать проверку на простое число для больших чисел?
Проверять делители только до √n. Пропускать чётные числа (кроме 2). Использовать решето Эратосфена для диапазонов. Тест Миллера-Рабина для очень больших чисел.

## 5. В чем разница между рекурсивной и итеративной реализацией Фибоначчи?
Рекурсивная — элегантная, но O(2ⁿ) без мемоизации (много повторных вызовов). Итеративная — O(n), использует цикл и меньше памяти. На практике итеративная предпочтительнее.

## 6. Какие методы отладки вы использовали?
console.log() для вывода промежуточных значений, вкладка Console в DevTools, пошаговое выполнение через breakpoints, проверка edge cases (пустой массив, null, отрицательные числа).

## 7. Как работает алгоритм Евклида для нахождения НОД и почему он эффективен?
НОД(a, b) = НОД(b, a % b), пока b ≠ 0. Эффективен, потому что остаток быстро уменьшается → O(log(min(a, b))) шагов.

## 8. Какие edge cases нужно учитывать при работе с массивами?
Пустой массив, массив из одного элемента, null/undefined, не-числовые значения, очень большие массивы, дубликаты, отрицательные числа.

## 9. Как улучшить функцию удаления дубликатов для больших массивов?
Использовать Set (O(n)) вместо includes (O(n²)): `[...new Set(arr)]`. Или объект-словарь для подсчёта. Для очень больших — сортировка + проход.

## 10. Какие принципы чистого кода вы применили?
Понятные имена функций и переменных, одна функция — одна задача, комментарии о сложности, обработка edge cases, отсутствие дублирования кода, читаемые отступы.
