## 1. Какое свойство включает CSS Grid и чем отличается от Flexbox?
display: grid. Grid — двумерная сетка (строки и колонки одновременно). Flexbox — одномерная.

## 2. Разница grid-template-columns и grid-auto-columns?
grid-template-columns задаёт явные колонки. grid-auto-columns — размер неявных колонок для элементов вне шаблона.

## 3. Функции repeat(), minmax(), auto-fit?
repeat(3, 1fr) — три колонки по 1fr. minmax(200px, 1fr) — минимум 200px, максимум 1fr. auto-fit — автоматически подбирает количество колонок.

## 4. Именованные grid-области?
grid-template-areas задаёт области по именам ("header header"), элементы привязываются через grid-area: header.

## 5. Система нумерации grid-линий?
Линии нумеруются с 1. grid-column: 1 / 3 — от первой до третьей линии.

## 6. Что такое gap?
Промежутки между строками и колонками. Лучше margin: не создаёт отступов по краям.

## 7. justify-items и align-items?
justify-items — выравнивание по горизонтали внутри ячейки. align-items — по вертикали.

## 8. auto-fill vs auto-fit?
auto-fill оставляет пустые колонки. auto-fit растягивает элементы на всё пространство.

## 9. grid-template-areas: правила именования?
Каждая строка — строка в кавычках. Имена без пробелов. Точка — пустая ячейка. Область прямоугольная.

## 10. Преимущества CSS Grid?
Двумерность, именованные области, адаптивность через auto-fit/minmax, вложенные сетки, меньше кода.
