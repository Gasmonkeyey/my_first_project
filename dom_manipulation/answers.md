## 1. В чем разница между innerHTML и textContent?
`innerHTML` возвращает/устанавливает HTML-разметку (парсит теги). `textContent` — только текст, без парсинга. `innerHTML` опасен для пользовательских данных (XSS). Для текста — `textContent`, для вставки HTML — `innerHTML`.

## 2. Как работает делегирование событий и какие преимущества?
Обработчик вешается на родителя, а не на каждый элемент. Событие всплывает от цели к родителю. Плюсы: меньше обработчиков, работает для динамически созданных элементов. Использовал для удаления элементов списка.

## 3. Разница между getElementById, querySelector, querySelectorAll?
`getElementById` — по id, возвращает один элемент, самый быстрый. `querySelector` — по CSS-селектору, первый найденный. `querySelectorAll` — все совпадения, возвращает NodeList.

## 4. Как предотвратить стандартное поведение и когда это нужно?
`event.preventDefault()`. Нужно при отправке формы (чтобы страница не перезагружалась), клике по ссылке, отправке данных через AJAX.

## 5. Разница между classList.add() и className?
`classList.add()` добавляет класс, не затрагивая остальные. `className = 'new'` заменяет все классы. `classList` безопаснее и удобнее (`toggle`, `remove`, `contains`).

## 6. Как создать элемент и добавить в DOM? Какой способ эффективнее?
`document.createElement()` + `appendChild()`. Эффективнее — через `DocumentFragment` для множества элементов (одна вставка в DOM вместо многих), или `insertAdjacentHTML()` для готовой разметки.

## 7. Что такое всплытие событий и как работает stopPropagation()?
Событие всплывает от целевого элемента вверх по дереву. `stopPropagation()` останавливает всплытие. Нужно, когда обработчик родителя не должен срабатывать.

## 8. Как получить данные из формы и в чем разница методов?
`new FormData(form)` — все поля сразу, удобно для отправки. `form.elements` — доступ к полям по имени. `querySelector` — по селекторам. FormData — самый современный и удобный.

## 9. Разница между input, change и keyup?
`input` — при каждом изменении значения (мгновенно). `change` — при потере фокуса или подтверждении. `keyup` — при отпускании клавиши. Для реального времени — `input`.

## 10. Как оптимизировать производительность при частых манипуляциях DOM?
Минимизировать количество обращений к DOM, использовать DocumentFragment, кэшировать ссылки на элементы, применять debounce/throttle, изменять классы вместо стилей, batch-обновления через requestAnimationFrame.
