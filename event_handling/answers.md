## 1. В чем разница между event.preventDefault() и event.stopPropagation()?
`preventDefault()` отменяет стандартное поведение браузера (переход по ссылке, отправка формы). `stopPropagation()` останавливает всплытие/погружение события по DOM-дереву. Первый — для поведения, второй — для распространения.

## 2. Как работает делегирование событий и какие преимущества?
Обработчик вешается на родителя, а не на каждый дочерний элемент. Событие всплывает от цели к родителю. Плюсы: меньше обработчиков (производительность), работает для динамически добавленных элементов, проще управлять.

## 3. Какие фазы жизненного цикла события?
Capturing (погружение — от корня к цели), Target (на целевом элементе), Bubbling (всплытие — от цели к корню). По умолчанию обработчики срабатывают на bubbling. `addEventListener` с третьим аргументом `true` — на capturing.

## 4. Разница между event.target и event.currentTarget?
`target` — элемент, на котором произошло событие (источник). `currentTarget` — элемент, к которому привязан обработчик. При делегировании target — дочерний, currentTarget — родитель.

## 5. Как создать кастомное событие?
`new CustomEvent('eventName', { detail: { data }, bubbles: true, cancelable: true })`, затем `element.dispatchEvent(event)`. В `detail` можно передать любые данные.

## 6. Что такое debounce и throttle?
Debounce — откладывает вызов до паузы (например, поиск по вводу). Throttle — ограничивает частоту вызовов (например, при скролле или resize). Debounce — «после последнего», throttle — «не чаще раза в N мс».

## 7. Как удалить обработчик и почему это важно?
`element.removeEventListener('click', handler)`. Важно для предотвращения утечек памяти (особенно при удалении элементов), для избежания множественных вызовов и конфликтов.

## 8. Как обрабатывать ошибки загрузки ресурсов?
У `img`, `script`, `link` есть события `load` (успех) и `error` (ошибка). Можно показать заглушку, скрыть элемент или записать в лог. Для `img` также `loadstart` и `loadend`.

## 9. Разница между addEventListener и onclick?
`addEventListener` позволяет добавить несколько обработчиков на одно событие, поддерживает capturing, можно удалить. `onclick` — только один обработчик (перезаписывается), не поддерживает capturing.

## 10. Как оптимизировать производительность при большом количестве событий?
Делегирование событий, debounce/throttle для частых событий (scroll, resize, mousemove), удаление ненужных обработчиков, использование `passive: true` для scroll/touch, `requestAnimationFrame` для визуальных обновлений.
